# ZALUPA (ZLP)

ERC-20 в сети Base с фиксированной эмиссией. Без владельца, без допэмиссии, без комиссий
на перевод. Исходники верифицированы.

**Контракт:** [`0x3fbA88B5633FF26A3969e6847b5dAFa4108a6FFB`](https://basescan.org/token/0x3fbA88B5633FF26A3969e6847b5dAFa4108a6FFB)
· **Пул:** [`0xe058bc…b8ec`](https://dexscreener.com/base/0xe058bcb6198450f23666bfe081351555aeeeb8ec)
· **Сайт:** [zalupa.world](https://zalupa.world)

```bash
npm install
npm test
```

Тесты гоняют настоящий EVM в памяти (`@ethereumjs/vm`) и настоящий байткод Uniswap V2 —
без нод, сети и Foundry.

## Свойства токена

- **Эмиссия фиксирована.** Всё чеканится в конструкторе. `mint` в ABI нет, владельца нет —
  допечатать нельзя никак. Проверяется тестом.
- **Никаких привилегий.** Ни pause, ни blacklist, ни комиссии на transfer. Никто, включая
  деплоера, не может тронуть чужой баланс или заблокировать перевод.
- **Permit (EIP-2612)** — allowance по подписи, без газа со стороны держателя.
- **Burnable** — каждый может сжечь свои токены.
- Имя, тикер, decimals и объём задаются при деплое, контракт под них не пересобирается.

3957 байт задеплоенного кода, transfer ~34.5k газа.

## Запуск своего токена

```bash
PRIVATE_KEY=0x... npm run launch
```

Спросит имя, тикер, decimals и эмиссию, покажет введённое **побайтно с видимыми пробелами**
и подтвердит перед отправкой. Дальше сам: деплой, обмен ETH на USDC, создание пары с
ценой $1.00.

Параметры спрашиваются, а не берутся из окружения, по конкретной причине: шелл раскрывает
`$$` в номер процесса, и `"$$K.1"` в двойных кавычках уехало бы в мейннет как `11519K.1`.
В prompt ничего не раскрывается.

Если что-то упадёт после деплоя, повторный запуск с `TOKEN_ADDRESS=0x...` пропустит деплой
и продолжит с обмена — второй токен не выпустится.

## Остальные команды

| | |
|---|---|
| `npm run verify 0xАДРЕС` | верификация исходников на Basescan |
| `npm run token-list 0xАДРЕС` | token list формата Uniswap, откуда кошельки берут логотип |
| `npm run pool` | создание пула на Uniswap V2 |
| `npm run nudge` | подгон цены пула до целевой одной покупкой |
| `npm run migrate` | перевод цены на $1.00 через новую пару с USDC |
| `npm run seed 0xАДРЕС` | микро-сделка, чтобы индексаторы увидели пару |
| `npm run logo` | нарезка `assets/logo-src.png` в 256/128/64/32 |
| `npm run check-key` | проверка приватного ключа без выхода в сеть |

Адрес принимается первым аргументом или через `TOKEN_ADDRESS=`. Все скрипты, которые тратят
деньги, печатают план, требуют `CONFIRM=yes` и прогоняют симуляцию до отправки.

## Почему столько кода вокруг простого токена

Каждый модуль появился из конкретного сбоя на мейннете:

- `rpc.mjs` — публичный узел отвечал «over rate limit» на пачку запросов
- `wait.mjs` — approve подтверждён на одном узле, симуляция ушла на отстающий, роутер упал
  с `TRANSFER_FROM_FAILED`
- `swap.mjs` — расчёт ETH руками не делил на курс, скрипт просил в 1882 раза больше нужного
- `address.mjs` — одна перепутанная буква в адресе давала «нужен TOKEN_ADDRESS», как будто
  переменной нет
- `env.mjs` — `TARGET_PRICE` вместо `TARGET_PRICE_USD` игнорировался молча, брался дефолт
- `creation.mjs` — платный эндпоинт Etherscan заменён бинарным поиском по блокам

## Чего у токена нет

- **Обеспечения.** Обменять ZLP на доллар не у кого и не за что. Цена — отношение резервов
  в пуле, а не привязка.
- **Ликвидности.** В пуле меньше доллара. Любая заметная сделка сдвинет цену в разы, а FDV
  получается умножением цены на всю эмиссию и осмысленной величиной не является.
- **Аудита.** Кирпичи OpenZeppelin аудированы, конкретно эта сборка — нет.

Учебный проект. Не предложение покупки и не финансовая рекомендация.
